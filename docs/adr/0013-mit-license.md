# MIT 许可证

公开仓库需要明确授权边界：选定 **MIT**，允许他人使用、修改与再分发，仅要求保留版权与许可声明。否决了暂不挂 license（公开也不算真正开源）、以及 GPL（对浏览器扩展分发摩擦更大）和 Apache-2.0（专利条款更重，本项目暂不需要）。

## Considered Options

- 无 LICENSE — 否决：法律上不清晰，也不符合开源惯例
- GPL-3.0 — 否决：扩展场景下 copyleft 成本高、采用意愿低
- Apache-2.0 — 可接受但更重；当前一人维护的扩展选更短的 MIT
- MIT（本决策）— 采用

## Consequences

根目录提供 `LICENSE`；README 标明 MIT。对外贡献默认按同一许可接受。
