# 壁纸：桌面过滤 + 显示缩放 + 内存预取池

Wallhaven 拉取增加桌面约束：`ratios=16x9,16x10`，仅 `image/jpeg` / `image/png`，下载后缩放到 `min(屏宽×dpr, 2560)` 再作显示用 data URL，避免 8K 原图拖垮「换一张」。

搜索还带用户选的纯度、分类、排序与标签。分类默认只要动漫；排序默认随机。选「热门」时固定 `topRange=1M`（接口要求热门必须带区间，设置里不另开一项）。标签跟着当前分类走（常规 / 动漫 / 人物各一套，多开并集），写入 `q=`，空格拼接、不加 `+`；关掉某类则去掉菜单里已经没有的已选标签。全关则不传 `q`，此时「相关」排序落到默认（随机）。从随机或最新勾上第一个标签则改到相关；热门、浏览、收藏不改。

当前壁纸仍只持久化一张。另维护内存预取池（3 张）：进页先保证当前图，空闲补池；手动换与日更共用换图会话（准备 / 提交），日界清空池。换图只走一次成图：解码完成后再上屏交叉淡入。池空时同样等成图，不用 thumbs 渐进预览（避免小图→全图连闪）。改纯度 / 分类 / 排序 / 标签会清池再预取，不立刻换当前图。

**B（2026-08-13）**：上面这些规则收进 `createWallpaperSurface`（`src/lib/wallpaper.ts`），预取池与换图会话成为它的内部实现，不再作为全局单例被起始页直接摆弄。取图、解码、落盘、上屏、本地自然日与预取排期都是注入口，因此日界作废旧池、改筛选丢弃在途预取、看过的图不重复入池这些原本只能手测的规则可以整条验证。起始页只说发生了什么（打开 / 日更 / 换一张 / 改筛选 / 导入 / 首启落地），不再各自拼「上屏 + 落盘 + 记 id + 清池 / 补池」。
