# 设置 UI：起始页内小弹窗，对标 macOS 系统设置

设置不做成独立浏览器 options 整页，而在起始页内以 **小弹窗** 打开；**信息架构**对标 macOS 系统设置（侧栏分类 + 右侧详情），材质贴起始页（不要不透明系统灰窗）。入口为左下角轻图标。与「少铬、壁纸为主」一致：弹窗出现时再展示铬，关闭后回到纯起始页。「换一张」不放在设置里。侧栏为 **通用**（打开方式、Bing）/ **壁纸** / **数据**——搜索不单独成类，首期只有 Bing 一项，并进通用。右侧不重复侧栏标题，只留关闭。每项上为标题与说明、下为控件一行；打开方式与 Bing 用分段（当前标签 / 新标签，国内 / 国际）；纯度与分类用同一行可多选胶囊（点开时按钮上 Face ID 成功态）。导出选项不放在列表里，点导出后再弹窗选包含图标 / 包含密钥。打开时从左下设置按钮放大弹出，关闭缩回；侧栏选中指示平移到当前项。不设「关于」分类：版本号、仓库外链与官网占位放在侧栏底部分割线下同一行；官网 `ytab.luoye.pro` 未上线时图标禁用（不是链接）；仓库外链始终新标签打开。瞬时成败用起始页顶部通知（砸下、果冻、右溜），盖过设置与首次启动。
