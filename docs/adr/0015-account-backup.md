# 账号备份：第三方登录 + 本机加密的一份云端密文

导入导出换机太绕，本机自动备份手感差且卸扩展仍可能丢。决定做 **账号备份**，不做多机对齐的云同步，也不用 chrome.storage.sync（塞不下图标）。只做 GitHub 登录；云端一份完整副本（含图标与 Wallhaven 密钥），本机用恢复口令加密后再传，服务器只见密文。Client ID 没配则界面不画登录。改完自动覆盖，后写盖住先写。卸扩展或换机后登录并解开整份拉回；本机已有网格再登录则问一次用云端还是用这台。可以不登录，没登录则卸扩展或换机丢光。用户侧导入导出撤掉。密文放 Cloudflare Worker + R2，接口挂在现有域名，不恢复官网；隐私说明写在设置里。Worker 与扩展同仓库分目录，不打进扩展包。

这是对 ADR-0007「首期不做账号系统 / 浏览器账号云同步」的重开：做账号备份，仍不做浏览器账号同步。ADR-0002 的 ZIP 只留给加密前的内部打包，用户不再看见 `.ytab`。
