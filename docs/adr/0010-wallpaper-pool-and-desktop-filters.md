# 壁纸：桌面过滤 + 显示缩放 + 内存预取池

Wallhaven 拉取增加桌面约束：`ratios=16x9,16x10`，仅 `image/jpeg` / `image/png`，下载后缩放到 `min(屏宽×dpr, 2560)` 再作显示用 data URL，避免 8K 原图拖垮「换一张」。

搜索还带用户选的纯度、分类、排序与标签。分类默认只要动漫；排序默认热门，并固定 `topRange=1M`（接口要求热门必须带区间，设置里不另开一项）。标签跟着当前分类走（常规 / 动漫 / 人物各一套，多开并集），写入 `q=`，空格拼接、不加 `+`；关掉某类则去掉菜单里已经没有的已选标签。全关则不传 `q`。

当前壁纸仍只持久化一张。另维护内存预取池（3 张）：进页先保证当前图，空闲补池；手动换与日更共用换图会话（准备 / 提交），日界清空池。换图只走一次成图：解码完成后再上屏交叉淡入。池空时同样等成图，不用 thumbs 渐进预览（避免小图→全图连闪）。改纯度 / 分类 / 排序 / 标签会清池再预取，不立刻换当前图。
